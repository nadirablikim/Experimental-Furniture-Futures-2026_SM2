# Found Vessel Pendants · 拾器吊灯

Interactive axonometric renders of three pendant lamps (Eclipse, Rise & Fall, Phase) made from found kitchen vessels and a fire pit.
Pick a lamp type, assign a found object to each part, add processes (heat-oxidise, perforate, fragment, sand), and switch between English and 中文.

Single self-contained page: `index.html` (three.js is loaded from jsDelivr).

## Publish with GitHub Pages
1. Create a new public repository and upload `index.html` (and this README).
2. Settings → Pages → Build and deployment → Source: *Deploy from a branch*, Branch: `main`, folder `/ (root)` → Save.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
